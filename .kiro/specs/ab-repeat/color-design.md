# 复读弹窗配色（v1.67 配色 / v1.68 间距）

## 范围
仅调整复读弹窗呈现；控件、顺序、布局、交互、保存格式及播放逻辑不变。不迁移全局主题，不改变其他页面按钮。

## 设计
采用 Material Design 3 的语义颜色角色，而非全局更换组件库或动态取色：
- Surface container：浅色近白、深色深灰；高不透明度降低歌词透出干扰，保留半透明效果（不是背景模糊）。
- Primary / on-primary：保留品牌红及白字，仅突出开始/停止复读。
- Secondary surface / on-surface：A/B、保存及未选择区间采用中性容器色与正文色。
- Selected container / on-container：浅粉或暗玫瑰容器，分别配深酒红或浅粉文字；不可统一使用白字。
- Error container / on-error-container：删除按钮采用低强调错误容器及相应前景色，而非整块高饱和红色。
- 只在复读控件清除全局按钮 tint，避免角色背景被全局着色覆盖；全局样式保持不变。

## 验证
静态检查验证 XML、资源完整性、对比度和历史页面保留约束。Robolectric 测试使用实际解析的浅深色资源和控件背景，检查文字对比度至少 4.5:1；不读取相对源码文件路径、不固定透明度或品牌色字面值。Android 编译和 Robolectric 已在 GitHub Actions run 43554497840（v1.68 / 13f2b6a）通过：158 项测试、0 失败。用户已确认复读功能真机测试无问题；不将该结论扩大为所有设备、所有字号的视觉验收。

v1.68 间距修正：顶部按钮间距、选择/已选择与 × 的间距、区间行底部间距均为 8dp。动态行间距测试已在上述 CI 实际执行。
