# 当前目录下载（v1.69）

- 入口：主界面更多菜单「下载当前目录歌曲」，仅服务器内可用；仅取点击时已显示的当前层音频快照，不递归、不重新列目录。
- 顺序串行下载；通过 serverId + getCacheKey 去重、隔离缓存。已下载文件（本地仍存在）跳过，启动每首前再次检查。
- 当前仅有单首异步下载，不存在批量队列。单首与批量共用新任务控制器，运行期间重复点击不会再发请求。
- 显示完成/总数、当前歌曲百分比与成功、跳过、失败数量。取消只取消剩余，当前首继续完成；失败继续下一首，无自动重试。
- 切目录不改变任务快照或播放队列；Activity 销毁停止剩余，当前首允许完成落盘，不再操作旧界面；不提供持久后台服务/进程死亡恢复。
- 失败不标记已下载，临时文件清理；未知/删除的服务器明确失败，不回退其他服务器。
- 独立按钮显式间距至少 8dp；测试覆盖队列时序、取消、异常、缓存隔离及真实对话框按钮。
- GitHub Actions 单测、构建通过并核验 APK 后交付；真机验收待用户完成，不打 tag。
