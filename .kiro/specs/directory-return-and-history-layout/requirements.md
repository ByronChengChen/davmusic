# v1.57 — 目录返回与历史行布局

## 已批准范围
1. 搜索页每条最近播放记录的删除按钮置于文字右侧，不再单独占一行；保留歌曲标题、位置、下载状态和独立删除点击，不改变播放/删除行为。
2. 进入子目录前保存父目录列表位置和像素偏移；返回父目录（含服务器列表）时，待对应列表数据到达后恢复，不再无条件回到顶部。
3. 首次进入新目录从顶部显示；滚动状态按服务器和路径隔离，不把子目录位置用于父目录，不接受旧异步回调跨导航恢复；保留现有搜索返回和 Activity 重建行为。
4. 不新增网络请求、不改目录缓存策略或播放队列；不修改远端。

## 明确不实现
歌曲及文件夹重命名。用户本轮已撤回第 3 项。
